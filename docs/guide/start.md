# Start with a folder

Your novel is a folder of Markdown files. Plot Device gives you a writing desk and
views of the story; the folder stays usable without it.

## Open or create a project

1. [Install Plot Device](../download.md), or run it from source during preparation.
2. Choose **Open folder…**.
3. Select your novel's folder. A project is recognized by its `novel.md` file.
   If the folder is not a project, the app offers to initialize it.
4. Give the project its own folder, rather than selecting your Documents folder
   or an entire Obsidian vault. A project may live inside a vault.

Do not nest one Plot Device project inside another. Existing Markdown files are
welcome: recognized frontmatter types determine how they appear in the app.
Unknown or untyped files are not deleted.

## Write the first chapter

Use **New chapter** in the manuscript binder, enter a title, and start writing.
Parts are optional; add them when they help you think about the book.

The chapter's title and story properties live in YAML frontmatter above its prose.
You can edit the properties through the inspector without touching that syntax.
The [file format](../file-format.md) explains the same files for other editors.

## Try the views

- **Write** keeps the draft and its properties close.
- **Overview** shows chapters, status, threads, and synopses.
- **Timeline** follows manuscript order or story dates.
- **Interactions** shows which characters share chapters.

There is also a place for the [outline you write yourself](story.md#your-outline),
which is different from the derived overview.

## Before working on a real manuscript

Set up an ordinary backup of the folder. Autosave is not a backup, and session-local
recovery is not persistent crash recovery. Read [Keep your work safe](safety.md)
before editing the same chapter in several applications.
