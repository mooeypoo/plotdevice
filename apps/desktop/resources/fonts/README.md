# Fonts packed into exported files

**David Libre** (Regular and Bold) is packed into Word manuscripts for Hebrew text (Milestone 22),
with "David" named as the font to use where a packed font isn't shown.

- From Google Fonts' repository: https://github.com/google/fonts/tree/main/ofl/davidlibre
- SIL Open Font License 1.1 (`OFL.txt`). Embedding is allowed (OS/2 fsType 0, installable).
