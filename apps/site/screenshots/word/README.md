# Word files for the screenshots

`he.docx` and `en.docx` are the Hebrew and English manuscripts the import preview's screenshot opens
(Milestone 23). They're copies of the test files built in `packages/import/src/docx-fixtures.test-support.ts`
(`HEBREW_BOOK`, `ENGLISH_BOOK`), saved here because the documentation site may read nothing from the
app's code but its words and colours (`site-reads-only-words-and-colours`). Write them again from that
file if it changes.
