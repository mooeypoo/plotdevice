title: Earlier versions, and restoring one
description: Go back to how a chapter, outline or page was earlier, and undo that if you change your mind.

import Ui from '~/components/Ui.astro'

Plot Device keeps earlier versions of every chapter, outline and page as you work: before it first changes a file, and then at most every ten minutes while you keep editing.

## See them

- **A chapter:** the book menu (the book's title) → **<Ui k="chapter-versions" />**.
- **An outline:** **⋯** beside the views → **<Ui k="outline-versions" />**.
- **A page:** **<Ui k="versions" />** on the page.

Versions are listed by time. Choose one to read it.

## Bring one back

- **<Ui k="versions-restore" />** puts it back. <Ui k="versions-restore-detail" />
- **<Ui k="versions-copy" />** keeps it as a separate file instead, leaving the current text as it is.

Versions are kept on your computer, outside the book's folder. See [Backups](/plotdevice/safe/backups/) for how long.
