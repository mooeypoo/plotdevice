Plot Device is in early versions for **Linux**, with an early beta for **Windows**. macOS comes later. It needs no account or internet connection.

## Download

Get the newest version from the [releases page](https://github.com/mooeypoo/plotdevice/releases):

- **The `.AppImage`** runs as it is: make it executable, then open it.
- **The `.deb`**, on Ubuntu or Debian, installs Plot Device with your other apps.
- **The `-setup.exe`**, on Windows, installs Plot Device and adds it to the Start menu.

### Windows is an early beta

Every change is tested on Windows automatically, including installing and removing the app, but it hasn't been used on real Windows computers yet. Expect rough edges, and please tell us about them: **☰ → <Ui k="report-problem" />**.

The installer isn't signed yet, so Windows may say **Windows protected your PC**. Choose **More info**, then **Run anyway**.

Your book is safe either way: it's plain files, each save swaps in a complete new file, and earlier versions are kept outside the book. See [Saving](/plotdevice/safe/saving/) and [Backups](/plotdevice/safe/backups/).

## New versions

When a newer version is out, Plot Device says so quietly in the top bar: **<Ui k="update-available" />**. It links to what's new and to this page; nothing is downloaded or installed for you. To check yourself, open **☰ → <Ui k="about" />** and choose **<Ui k="update-check" />**.

To do this, Plot Device asks GitHub once a day whether a newer version is out. Nothing about you or your writing is sent. You can turn it off in [Settings](/plotdevice/reference/settings/).

## Open it

The first time, Plot Device greets you with two choices: **<Ui k="welcome-new-project" />** starts a new book in a folder you choose, and **<Ui k="welcome-open-project" />** opens a book folder you already have.

Your book is an ordinary folder of Markdown files. Plot Device keeps its own settings, such as the language and theme, on your computer, never inside the book.
