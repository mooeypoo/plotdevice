Plot Device is in early versions for **Windows** and **Linux**. macOS comes later. It needs no account or internet connection.

## Download

Choose your computer. Everything is on the [releases page](https://github.com/mooeypoo/plotdevice/releases).

<Tabs syncKey="system">
<TabItem label="Windows">

Download **the `-setup.exe`** and open it. It installs Plot Device and adds it to the Start menu.

The installer isn't signed yet, so Windows may say **Windows protected your PC**. Choose **More info**, then **Run anyway**.

**Windows is an early beta.** Every change is tested on Windows automatically, including installing and removing the app, but it hasn't been used on real Windows computers yet. Expect rough edges, and please tell us about them: **☰ → <Ui k="report-problem" />**.

</TabItem>
<TabItem label="Linux">

Download one of these:

- **The `.AppImage`** runs as it is, once it's allowed to: see below.
- **The `.deb`**, on Ubuntu or Debian, installs Plot Device with your other apps.

**Allow the AppImage to run.** Downloads aren't allowed to run until you say so, so at first a double-click on the AppImage does nothing, or opens it as a disk. Once, after downloading:

- **In Files:** right-click the AppImage → **Properties** → turn on **Executable as Program**.
- **Or in a terminal:** `chmod +x ~/Downloads/plotdevice-*.AppImage`

Then double-click it to open Plot Device. A newer version is a new download, so allow it once again.

</TabItem>
<TabItem label="macOS">

**Coming soon.** A version for the Mac is on its way. It needs an Apple developer account to be signed, so [supporting Plot Device](/support/) helps it arrive sooner.

</TabItem>
</Tabs>

Your book is safe either way: it's plain files, each save swaps in a complete new file, and earlier versions are kept outside the book. See [Saving](/docs/safe/saving/) and [Backups](/docs/safe/backups/).

## New versions

When a newer version is out, Plot Device says so quietly in the top bar: **<Ui k="update-available" />**. It links to what's new and to this page; nothing is downloaded or installed for you. To check yourself, open **☰ → <Ui k="about" />** and choose **<Ui k="update-check" />**.

To do this, Plot Device asks GitHub once a day whether a newer version is out. Nothing about you or your writing is sent. You can turn it off in [Settings](/docs/reference/settings/).

## Open it

The first time, Plot Device greets you with two choices: **<Ui k="welcome-new-project" />** starts a new book in a folder you choose, and **<Ui k="welcome-open-project" />** opens a book folder you already have.

Your book is an ordinary folder of text files. Plot Device keeps its own settings, such as the language and theme, on your computer, never inside the book.
