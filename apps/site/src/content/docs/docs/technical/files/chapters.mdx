title: Chapters and the contents
description: How chapter files and CONTENTS.md hold the book's text and order.
---

## A chapter

Each chapter is a file in `manuscript/`:

```markdown
---
title: The Crossing
id: ch-d3m0c2
---
The ferry left Szeged an hour late.

* * *

"You're thinner than your photograph," said Aunt Bea.
```

- `title` is the chapter's name. Renaming a chapter changes this line, never the file's name.
- `id` helps Plot Device recognise the chapter if its file is renamed elsewhere. It always asks before relinking.
- `* * *` is a scene break.
- Anything else you add above the text, or Markdown Plot Device doesn't show, is kept exactly as written.

## A poem

A chapter that is a poem says `form: poem` above its text:

```markdown
---
title: Evening in the Orchard
id: ch-poem-en
form: poem
---
The evening settles on the orchard\
and salt lies quiet on the leaves\
I count the trees

The wind says nothing\
and the sea remembers\
everything we forgot
```

- `form: poem` is the only difference from prose. Without `form`, a chapter is prose. A value Plot Device doesn't know is kept as written, and the chapter is shown as prose.
- A `\` at the end of a line is Markdown's line break: the line ends there. A blank line starts a new stanza. Plot Device writes both as you type; on screen, the `\` never shows.
- So any Markdown app shows the poem with its lines and stanzas, and switching the Poem setting off or on changes only the `form` line.
- An untitled poem has `title: ""`. Plot Device then shows its first line in the sidebar, and exports it with no heading.

Versions of Plot Device from before poems open a poem as prose with its line breaks: nothing is lost.

## The contents

`CONTENTS.md` is the book's reading order, and also a table of contents a person can read:

```markdown
# The Salt Orchard

- [Prologue](manuscript/prologue.md)
- Part One: Arrival
  - [The Crossing](manuscript/the-crossing.md)
  - [The Orchard Gate](manuscript/the-orchard-gate.md)
- [Epilogue](manuscript/epilogue.md)
```

- A list item with a link to a chapter file is a chapter; its place in the list is its place in the book.
- A list item without a link, with chapters under it, is a part.
- Reordering lines here, in any app, reorders the book. File names and folders don't matter.

A chapter file the contents doesn't mention waits **on the side**; Plot Device never adds it by itself.

## Direction

A paragraph or phrase set to a direction other than the book's (see [Hebrew and English in one book](/docs/writing/hebrew-and-english/)) is written in the notation Pandoc understands, and only where it's needed:

```markdown
[Ilka Varga]{dir=ltr} חיכתה על הרציף.
```

Other apps show it as plain text, and nothing is lost.
