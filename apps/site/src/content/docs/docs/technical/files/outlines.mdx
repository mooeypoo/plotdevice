---
title: Outline files
description: How an outline is written as an ordinary Markdown list.
---

An outline is a file in `outlines/`, written the way you might write a plan by hand:

```markdown
# Main story

## Beginning

- Ilka inherits the orchard, see [The Crossing](../manuscript/the-crossing.md)
  - [Aunt Bea](../characters/bea.md) is waiting at the landing
- The gate is chained

## End

- The orchard is sold, but not for money
```

| Markdown | On the board |
|---|---|
| `# Main story` | The outline's title (optional) |
| `## Beginning` | A section: a column |
| `- Ilka inherits…` | A card |
| `  - Aunt Bea is waiting…` | A detail inside the card |
| `[The Crossing](../manuscript/the-crossing.md)` | A link to a chapter, character, place or note |

## Lining up with another outline

A line under a section's heading, with one link to a section of another outline, lines the two up on the [timeline](/docs/planning/timeline/):

```markdown
## Waiting at the landing
At the same time as [Beginning](main-story.md#beginning)

- Meets Ilka off the ferry
```

The words around the link are yours; Plot Device writes "At the same time as" in the book's language. The part after `#` is the other section's heading, lowercased, with spaces as `-` and punctuation left out. Links to chapters or pages don't line anything up.

Plot Device changes only the lines a change needs. Anything it doesn't show, such as a table or a quote, is kept where it is, and moves with its card.
