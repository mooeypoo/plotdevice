תפריט הספר (שם הספר בסרגל העליון) ← **<Ui k="export-book" />** מחבר את כל הפרקים, בסדר הקריאה, לקובץ Markdown אחד. בוחרים איפה לשמור אותו; כברירת מחדל, מחוץ לתיקיית הספר.

## מה יש בו

- חלקים הופכים לכותרות `#`, ופרקים לכותרות `##`, ממוספרים כפי ש־Plot Device מציגה אותם.
- אחרי כל כותרת בא הטקסט של הפרק, ללא שינוי.
- פרקים שתחת **<Ui k="navigator-not-in-book" />** לא נכללים. אם קובץ של פרק חסר, הספר מיוצא בלעדיו, ו־Plot Device מודיעה איזה.

```markdown
# חלק ראשון: הגעה

## 2. המעבר

המעבורת יצאה מסגד באיחור של שעה. …
```

## ‏Word, ‏EPUB ו־PDF

הקובץ המיוצא הוא Markdown תקני, כולל כיווני עברית ואנגלית, כך ש־[Pandoc](https://pandoc.org) יכולה להמיר אותו ל־Word, ל־EPUB או ל־PDF. למשל: `pandoc book.md -o book.docx`.
