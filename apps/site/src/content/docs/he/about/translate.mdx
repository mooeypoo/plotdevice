Plot Device בנויה כדי שיתרגמו אותה. האפליקציה והאתר הזה לוקחים את המילים שלהם מקבצים פשוטים, והוספת שפה היא בעיקר כתיבה.

## האפליקציה

1. מעתיקים את `packages/i18n/src/messages/en.json` לקובץ `<code>.json` (למשל `fr.json`).
2. מתרגמים כל הודעה. את `$1`, ‏`$2` ו־`{{PLURAL:…}}` משאירים כמו שהם: האפליקציה ממלאת אותם.
3. מוסיפים את השפה לקטלוגים ב־`packages/i18n/src/translator.ts`. בדיקה אוטומטית מוודאת שכל הודעה תורגמה.

## האתר

1. מוסיפים את השפה ל־`locales` ב־`apps/site/astro.config.ts`, עם `dir: 'rtl'` אם היא נכתבת מימין לשמאל.
2. מתרגמים דפים לתוך `apps/site/src/content/docs/<code>/`, עם אותם שמות קבצים. דפים שעוד לא תורגמו מציגים את האנגלית עם הודעה, כך שאפשר להתקדם דף אחרי דף.
3. בכל דף מתורגם, ב־frontmatter, קובעים `sourceHash` לפי הערך של הדף האנגלי בדוח שלמטה. כשהדף האנגלי ישתנה, הדוח יציין שהתרגום צריך עדכון.
4. מוסיפים את השפה ל־`LANGUAGES` ב־`apps/site/screenshots/screens.shots.ts`, כדי שצילומי המסך באתר יראו את האפליקציה בשפה הזו.

שמות הכפתורים במדריך מגיעים מהאפליקציה, דרך `<Ui k="…" />`, כך שהם מופיעים בשפה החדשה ברגע שהאפליקציה מדברת אותה.

## הדוח

```sh
pnpm site:translations
```

מונה, לכל שפה, את הדפים שעוד לא תורגמו ואת אלה שהאנגלית שלהם השתנתה מאז.
