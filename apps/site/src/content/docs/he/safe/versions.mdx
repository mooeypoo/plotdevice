import Ui from '~/components/Ui.astro'

Plot Device שומרת גרסאות קודמות של כל פרק, מתווה ודף תוך כדי עבודה: לפני שהיא משנה קובץ בפעם הראשונה, ואחר כך לכל היותר פעם בעשר דקות, כל עוד ממשיכים לערוך.

## רואים אותן

- **פרק:** תפריט הספר (שם הספר) ← **<Ui k="chapter-versions" />**.
- **מתווה:** ה־**⋯** שליד התצוגות ← **<Ui k="outline-versions" />**.
- **דף:** **<Ui k="versions" />** שבדף.

הגרסאות מסודרות לפי זמן. בוחרים אחת כדי לקרוא אותה.

## מחזירים אחת

- **<Ui k="versions-restore" />** מחזיר אותה. <Ui k="versions-restore-detail" />
- **<Ui k="versions-copy" />** שומר אותה כקובץ נפרד, והטקסט הנוכחי נשאר כמו שהוא.

הגרסאות נשמרות במחשב, מחוץ לתיקיית הספר. כמה זמן? ראו [גיבויים](/plotdevice/he/safe/backups/).
