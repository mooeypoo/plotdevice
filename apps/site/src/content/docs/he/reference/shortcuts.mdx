במק משתמשים ב־**⌘** במקום **Ctrl**. תפריטים ורשימות עובדים גם עם החיצים, **Home**, **End** ו־**Escape**. בממשק מימין לשמאל, החיצים ימינה ושמאלה מתהפכים בהתאם.

## כתיבה

| לוחצים | כדי |
|---|---|
| **Ctrl+B** | מודגש |
| **Ctrl+I** | נטוי |
| **Enter** | פסקה חדשה |
| **Shift+Enter** | ירידת שורה בתוך פסקה |
| **Ctrl+Z** / **Ctrl+Shift+Z** | ביטול / ביצוע מחדש |
| **Ctrl+Shift+F** | הפעלה וכיבוי של מצב ריכוז |
| **Escape** | יציאה ממצב ריכוז |
| **Ctrl+Shift+R** | הצגה והסתרה של חומרי העזר |

## סידור

| לוחצים | על | כדי |
|---|---|---|
| **Alt+↑** / **Alt+↓** | פרק ברשימה | להזיז אותו מוקדם או מאוחר יותר בספר |
| **Alt+↑** / **Alt+↓** | כרטיס או פרט | להזיז אותו בתוך הרשימה שלו |
| **Alt+←** / **Alt+→** | כרטיס | להעביר אותו למקטע הסמוך |
| **Enter** או **F2** | כרטיס | לערוך את הטקסט שלו |
| **Delete** | כרטיס | למחוק אותו (אחרי שאלה) |
| **Alt+↑** / **Alt+↓** | חומר עזר מוצמד | להזיז אותו על המדף |

## האפליקציה

| לוחצים | כדי |
|---|---|
| **Ctrl+,** | הגדרות |
| **Ctrl+O** | פתיחת ספר |
| **Ctrl+=** / **Ctrl+−** / **Ctrl+0** | הגדלה / הקטנה / גודל רגיל |
| **F11** | מסך מלא |
