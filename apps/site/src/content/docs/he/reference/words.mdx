title: המילים של Plot Device
description: מה כל מילה ב־Plot Device אומרת. שם אחד לכל רעיון.
---

import Ui from '~/components/Ui.astro'

| מילה | פירוש |
|---|---|
| **ספר** (או פרויקט) | רומן, סיפור או מערכה: תיקייה של קבצים. |
| **תבנית** | מה שספר חדש מתחיל איתו: סיפור ארוך, סיפור קצר, מערכה של D&D, או ריק. אפשר לשנות בה הכול אחר כך. |
| **פרק** | היחידה שכותבים בה: קובץ אחד. ספר יכול לקרוא לפרקים שלו בשם אחר, כמו מפגשים. |
| **חלק** | קבוצה של פרקים עם שם. רשות. |
| **<Ui k="navigator-not-in-book" />** | פרקים שמחוץ לסדר הקריאה, והטקסט שלהם שלם. |
| **<Ui k="workspace-write" />** | המקום שבו כותבים פרקים. |
| **<Ui k="workspace-story" />** | המקום שבו מתכננים. יש בו שני חלקים, **<Ui k="story-plot" />** ו־**<Ui k="story-world" />**. |
| **<Ui k="story-plot" />** | מה שקורה בסיפור: המתווים וציר הזמן. |
| **<Ui k="story-world" />** | מי ואיפה: הדפים של הספר, לפי סוג. |
| **מתווה** | תוכנית שאפשר לסדר מחדש; יכולים להיות רבים. |
| **מתווה ראשי** | המתווה שמסומן **<Ui k="outline-main-badge" />**. המקטעים שלו הם העמודות של ציר הזמן. |
| **מקטע** | כותרת במתווה: עמודה בלוח. |
| **כרטיס** | פריט במתווה. |
| **פרט** | משהו בתוך כרטיס. |
| **<Ui k="story-timeline" />** | כל המתווים זה לצד זה, שורה לכל אחד. |
| **קו עלילה** | מתווה, כשורה בציר הזמן. |
| **יישור** | לומר שמקטע בקו עלילה אחד קורה באותו זמן כמו רגע בקו אחר. |
| **<Ui k="outline-set-aside" />** | להזיז מתווה מהדרך, אל מחוץ לציר הזמן, בלי למחוק כלום. |
| **דף** | דמות, מקום, הערה, או דף מכל סוג אחר. |
| **סוג דפים** | סוג של דפים שהספר שומר, בתיקייה משלו: דמויות, מקומות והערות, או סוג משלך, כמו פלגים. |
| **קשר** | איך דף אחד מתחבר לדף אחר, במילים שלך: „הדודה של אילקה”. |
| **<Ui k="tags" />** | מילים משלך לקיבוץ דפים, כמו „משפחת ורגה”. |
| **<Ui k="shelf" />** | דפים שנשמרים לצד העמוד שכותבים. |
| **גרסה** | איך קובץ נראה קודם, שמורה כדי שאפשר יהיה לחזור. |
| **גיבוי** | עותק של הספר כולו, שנשמר בתיקייה שבוחרים. |
| **ייצוא** | כל הספר כקובץ אחד. |
