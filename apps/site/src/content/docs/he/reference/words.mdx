| מילה | פירוש |
|---|---|
| **ספר** (או פרויקט) | רומן אחד: תיקייה של קבצים. |
| **פרק** | היחידה שכותבים בה: קובץ אחד. |
| **חלק** | קבוצה של פרקים עם שם. רשות. |
| **<Ui k="navigator-not-in-book" />** | פרקים שמחוץ לסדר הקריאה, והטקסט שלהם שלם. |
| **<Ui k="workspace-write" />** | המקום שבו כותבים פרקים. |
| **<Ui k="workspace-story" />** | המקום שבו מתכננים: מתווים, דמויות, מקומות והערות. |
| **מתווה** | תוכנית שאפשר לסדר מחדש; יכולים להיות רבים. |
| **מקטע** | כותרת במתווה: עמודה בלוח. |
| **כרטיס** | פריט במתווה. |
| **פרט** | משהו בתוך כרטיס. |
| **דף** | דמות, מקום או הערה. |
| **<Ui k="shelf" />** | דפים שנשמרים לצד העמוד שכותבים. |
| **גרסה** | איך קובץ נראה קודם, שמורה כדי שאפשר יהיה לחזור. |
| **ייצוא** | כל הספר כקובץ אחד. |
