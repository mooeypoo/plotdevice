Plot Device זמינה בגרסאות מוקדמות ל־**Linux** ול־**Windows**. גרסה ל־macOS תגיע בהמשך. לא צריך בשבילה חשבון או חיבור לאינטרנט.

## הורדה

את הגרסה החדשה ביותר מורידים מ[דף הגרסאות](https://github.com/mooeypoo/plotdevice/releases):

- **‏Linux:** את קובץ ה־`.AppImage` אפשר להריץ כמו שהוא (מסמנים אותו כקובץ הרצה ופותחים). ב־Ubuntu או ב־Debian, קובץ ה־`.deb` מתקין את Plot Device לצד שאר האפליקציות.
- **‏Windows:** מריצים את קובץ ההתקנה `-setup.exe` ועוברים על השלבים.

## פתיחה

בפעם הראשונה, Plot Device מציעה שתי אפשרויות: **<Ui k="welcome-new-project" />** פותח ספר חדש בתיקייה שבוחרים, ו־**<Ui k="welcome-open-project" />** פותח תיקיית ספר שכבר קיימת.

הספר הוא תיקייה רגילה של קובצי Markdown. ההגדרות של Plot Device עצמה, כמו השפה וערכת הצבעים, נשמרות במחשב, אף פעם לא בתוך הספר.
