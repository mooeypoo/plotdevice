Plot Device זמינה בגרסאות מוקדמות ל־**Linux**, ובגרסת בטא מוקדמת ל־**Windows**. גרסה ל־macOS תגיע בהמשך. לא צריך בשבילה חשבון או חיבור לאינטרנט.

## הורדה

את הגרסה החדשה ביותר מורידים מ[דף הגרסאות](https://github.com/mooeypoo/plotdevice/releases):

- **קובץ ה־`.AppImage`** רץ כמו שהוא: מסמנים אותו כקובץ הרצה ופותחים.
- **קובץ ה־`.deb`**, ב־Ubuntu או ב־Debian, מתקין את Plot Device לצד שאר האפליקציות.
- **קובץ ה־`-setup.exe`**, ב־Windows, מתקין את Plot Device ומוסיף אותה לתפריט התחל.

### Windows בגרסת בטא מוקדמת

כל שינוי נבדק אוטומטית גם ב־Windows, כולל התקנה והסרה של האפליקציה, אבל עוד לא השתמשו בה במחשבי Windows אמיתיים. יכול להיות שיהיו דברים לא מלוטשים, ונשמח לשמוע עליהם: **☰ ← <Ui k="report-problem" />**.

תוכנת ההתקנה עוד לא חתומה, ולכן Windows עשויה להציג את ההודעה **Windows protected your PC**. בוחרים **More info**, ואז **Run anyway**.

הספר שלכם בטוח בכל מקרה: אלה קבצים רגילים, כל שמירה מחליפה את הקובץ בעותק שלם וחדש, וגרסאות קודמות נשמרות מחוץ לספר. ראו [שמירה](/plotdevice/he/safe/saving/) ו[גיבויים](/plotdevice/he/safe/backups/).

## גרסאות חדשות

כשיוצאת גרסה חדשה, Plot Device מציינת זאת בשקט בסרגל העליון: **<Ui k="update-available" />**. משם יש קישור למה שחדש ולדף הזה; שום דבר לא מורד או מותקן מעצמו. כדי לבדוק בעצמכם, פותחים **☰ ← <Ui k="about" />** ובוחרים **<Ui k="update-check" />**.

לשם כך Plot Device שואלת את GitHub פעם ביום אם יצאה גרסה חדשה. שום מידע על הכותבים או על הכתיבה לא נשלח. אפשר לכבות את זה ב[הגדרות](/plotdevice/he/reference/settings/).

## פתיחה

בפעם הראשונה, Plot Device מציעה שתי אפשרויות: **<Ui k="welcome-new-project" />** פותח ספר חדש בתיקייה שבוחרים, ו־**<Ui k="welcome-open-project" />** פותח תיקיית ספר שכבר קיימת.

הספר הוא תיקייה רגילה של קובצי Markdown. ההגדרות של Plot Device עצמה, כמו השפה וערכת הצבעים, נשמרות במחשב, אף פעם לא בתוך הספר.
