ההגדרות שייכות לך, לא לספר: הן נשמרות במחשב, ופתיחת הספר במקום אחר לא לוקחת אותן איתו.

## ☰ ← <Ui k="settings-open" />

או **Ctrl+,** (‏⌘,).

- **<Ui k="settings-language" />**: עברית או אנגלית, לתפריטים ולכפתורים. לספר נשארת השפה שלו.
- **<Ui k="settings-theme" />**: <Ui k="theme-system" />, <Ui k="theme-light" /> או <Ui k="theme-dark" />.
- **<Ui k="settings-check-updates" />**: פועלת מההתחלה. פעם ביום Plot Device שואלת את GitHub אם יצאה גרסה חדשה, ומציינת זאת בסרגל העליון. שום מידע על הכותבים או על הכתיבה לא נשלח. ראו [גרסאות חדשות](/he/docs/start/install/#גרסאות-חדשות).
- **<Ui k="settings-advanced" />** ← **<Ui k="settings-plain-text" />**: כבויה מההתחלה. פרקים, דפים ומתווים בתצוגת טקסט נפתחים עם כל סימוני ה־Markdown, לתיקונים ידניים. ראו [טקסט פשוט](/he/docs/writing/formatting/#טקסט-פשוט).
- **<Ui k="settings-advanced" />** ← **<Ui k="settings-plain-text-switch" />**: כבויה מההתחלה. כפתור **<Ui k="plain-text-switch" />** ליד **<Ui k="toolbar-format" />** עובר לטקסט פשוט ובחזרה, כמו **Ctrl+Shift+M**.
