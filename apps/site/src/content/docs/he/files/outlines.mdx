---

מתווה הוא קובץ בתיקייה `outlines/`, שנכתב כמו שכותבים תוכנית ביד:

```markdown
# העלילה

## התחלה

- אילקה יורשת את המטע, ראו [המעבר](../manuscript/המעבר.md)
  - [דודה בּיה](../characters/ביה.md) מחכה במעגן
- השער נעול

## סוף

- המטע נמכר, אבל לא תמורת כסף
```

| ‏Markdown | בלוח |
|---|---|
| `# העלילה` | שם המתווה (לא חובה) |
| `## התחלה` | מקטע: עמודה |
| `- אילקה יורשת…` | כרטיס |
| `  - דודה בּיה מחכה…` | פרט בתוך הכרטיס |
| `[המעבר](../manuscript/המעבר.md)` | קישור לפרק, לדמות, למקום או להערה |

## יישור עם מתווה אחר

שורה מתחת לכותרת של מקטע, עם קישור אחד למקטע במתווה אחר, מיישרת את השניים ב[ציר הזמן](/plotdevice/he/planning/timeline/):

```markdown
## מחכה במעגן
במקביל ל־[התחלה](העלילה.md#התחלה)

- פוגשת את אילקה כשהיא יורדת מהמעבורת
```

המילים סביב הקישור הן שלך; Plot Device כותבת „במקביל ל־” בשפת הספר. מה שאחרי `#` הוא הכותרת של המקטע השני, באותיות קטנות, עם `-` במקום רווחים ובלי סימני פיסוק. קישורים לפרקים או לדפים לא מיישרים כלום.

Plot Device משנה רק את השורות שהשינוי צריך. כל מה שהיא לא מציגה, כמו טבלה או ציטוט, נשאר במקומו וזז יחד עם הכרטיס שלו.
