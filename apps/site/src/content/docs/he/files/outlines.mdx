title: קובצי מתווים
description: איך מתווה נכתב כרשימת Markdown רגילה.
---

מתווה הוא קובץ בתיקייה `outlines/`, שנכתב כמו שכותבים תוכנית ביד:

```markdown
# העלילה

## התחלה

- אילקה יורשת את המטע, ראו [המעבר](../manuscript/המעבר.md)
  - [דודה בּיה](../characters/ביה.md) מחכה במעגן
- השער נעול

## סוף

- המטע נמכר, אבל לא תמורת כסף
```

| ‏Markdown | בלוח |
|---|---|
| `# העלילה` | שם המתווה (לא חובה) |
| `## התחלה` | מקטע: עמודה |
| `- אילקה יורשת…` | כרטיס |
| `  - דודה בּיה מחכה…` | פרט בתוך הכרטיס |
| `[המעבר](../manuscript/המעבר.md)` | קישור לפרק, לדמות, למקום או להערה |

Plot Device משנה רק את השורות שהשינוי צריך. כל מה שהיא לא מציגה, כמו טבלה או ציטוט, נשאר במקומו וזז יחד עם הכרטיס שלו.
