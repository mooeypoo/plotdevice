In **<Ui k="workspace-story" />**, the side list has three groups: **<Ui k="story-character" />**, **<Ui k="story-place" />** and **<Ui k="story-note" />**. Each page is a Markdown file in its own folder.

## Add a page

Choose **+ <Ui k="new-character" />**, **+ <Ui k="new-place" />** or **+ <Ui k="new-note" />**, and give it a name.

## Write it

Click a page to open it. <Ui k="reference-hint" />

The description is what the references shelf shows first; the details open under it. Use headings and lists in the details as you like.

## Rename

**<Ui k="reference-rename" />** changes the page's name; **<Ui k="reference-rename-file" />** changes its file's name. A page also has **<Ui k="versions" />**.

## Other names

A character called "Bea Halmi" may be "Aunt Bea" in the text. Add the other names to the page's file as `aka: [Aunt Bea, Bea]`, and searching for any of them finds the page. See [Character, place and note pages](/plotdevice/files/pages/).
