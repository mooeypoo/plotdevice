---
title: Keyboard shortcuts
description: Every shortcut in Plot Device, for writing, arranging and moving around.
---

On a Mac, use **⌘** where it says **Ctrl**. Menus and lists also work with the arrow keys, **Home**, **End** and **Escape**.

## Writing

| Press | To |
|---|---|
| **Ctrl+B** | Bold |
| **Ctrl+I** | Italic |
| **Enter** | New paragraph |
| **Shift+Enter** | Line break inside a paragraph |
| **Ctrl+Z** / **Ctrl+Shift+Z** | Undo / redo |
| **Ctrl+Shift+F** | Focus mode on or off |
| **Escape** | Leave focus mode |
| **Ctrl+Shift+R** | Show or hide the references |

## Arranging

| Press | On | To |
|---|---|---|
| **Alt+↑** / **Alt+↓** | A chapter in the list | Move it earlier or later in the book |
| **Alt+↑** / **Alt+↓** | A card or detail | Move it within its list |
| **Alt+←** / **Alt+→** | A card | Move it to the neighbouring section |
| **Enter** or **F2** | A card | Edit its text |
| **Delete** | A card | Delete it (after asking) |
| **Alt+↑** / **Alt+↓** | A pinned reference | Move it on the shelf |

## The app

| Press | To |
|---|---|
| **Ctrl+,** | Settings |
| **Ctrl+O** | Open a book |
| **Ctrl+=** / **Ctrl+−** / **Ctrl+0** | Larger / smaller / normal size |
| **F11** | Full screen |
