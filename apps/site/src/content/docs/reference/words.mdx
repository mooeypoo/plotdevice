---
title: Words used in Plot Device
description: What each word in Plot Device means. One name for each idea.
---

import Ui from '~/components/Ui.astro'

| Word | Means |
|---|---|
| **Book** (or project) | One novel: a folder of files. |
| **Chapter** | The unit you write in: one file. |
| **Part** | A named group of chapters. Optional. |
| **<Ui k="navigator-not-in-book" />** | Chapters kept outside the reading order, with their text intact. |
| **<Ui k="workspace-write" />** | Where you write chapters. |
| **<Ui k="workspace-story" />** | Where you plan: outlines, characters, places and notes. |
| **Outline** | A plan you can rearrange; there can be many. |
| **Section** | A heading in an outline: a column on the board. |
| **Card** | An item in an outline. |
| **Detail** | Something inside a card. |
| **Page** | A character, place or note. |
| **<Ui k="shelf" />** | Pages kept beside the page you're writing. |
| **Version** | How a file was earlier, kept so you can go back. |
| **Export** | The whole book as one file. |
