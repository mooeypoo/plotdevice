# Plot Device

A writing studio for fiction authors, in English and Hebrew. Your novel lives in an ordinary folder of Markdown files, readable and editable in any other app, with Plot Device as a calm place to write and plan it.

**Status:** early development. Phase 0, the technical experiments, is complete; the first implementation milestone is being planned.
